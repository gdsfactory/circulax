# R3_CMC three-terminal resistor

`circulax.components.r3.R3_CMC` implements R3_CMC 1.1.2, level 1003,
from VA-Models commit `6099b4e12e6f66ff530f59b8d01fb909094be85a`.
It is a native JAX current/charge component. Normal simulation requires
neither bosdi, OSDI binaries nor a Verilog-A compiler.

Ports are `n1`, `nc`, `n2`, `dt`. `nc` is the body/tub control terminal.
`dt` is a temperature-rise port in kelvin, whose flow represents watts.
Ground `dt` for a fixed temperature, or leave it as a circuit node for the
built-in thermal network. Internal states `v_i1`, `v_i2`, `i_b_re1`,
`i_b_re2` retain the contact nodes and branch currents, including the
zero-resistance contact voltage constraints.

```python
from circulax.components.r3 import R3_CMC

model = R3_CMC(rsh=100., rc=2., c1=1, c2=2,
               gth0=0.01, cth0=1e-6, tc1=0.002)
# Register {"r3": R3_CMC} in compile_circuit's models mapping.
```

The API retains the VA parameters, plus `_temperature` (ambient kelvin,
default 300.15) and `_mfactor` (parallel multiplicity, default 1). Geometry
uses the VA SI units, internally converted to micrometers. `scale=1`,
`imax=1 A`, `rthresh=1e-3 ohm` restore the simulator-query defaults. The
`gmin` query uses its zero fallback. Model parameters cover sheet/contact
resistance, geometry, mismatch, body modulation, junction current/charge,
temperature coefficients and self-heating. See the vendored `r3_cmc.txt`
and VA declarations for all parameter details. Noise and simulator
diagnostics are outside this deterministic F/Q model.

A single coupled core preserves nonlinear contacts, charge and thermal
coupling. DC, AC, transient and HB use `F + dQ/dt = 0`. Numeric parameters
remain differentiable. A subcircuit would duplicate internal unknowns
without reducing the coupled core here.

Tests compare 12 stored OSDI biases across default, finite-contact,
junction/thermal, linear, full-pinch-off and mismatch cases, at ambient
280–340 K. They check F/Q, voltage derivatives, electrical conservation,
JIT/vmap, parameter gradients and linear and self-heating netlist DC solves.
An optional test recompiles the pinned VA and independently checks the oracle.

**Reference limitation:** for the tested `sw_accpo=2` full-pinch-off setting,
OpenVAF's analytic conductance matrix disagrees with finite differences of
its own residual. Native JAX derivatives agree with finite differences of
both implementations. Those cases use central finite differences of the
OSDI residual (`g_fd` in `reference.json`); other cases compare its analytic
matrix. Validation covers tested settings, not the entire parameter space.
Translation guards can differ outside physically meaningful ranges.

CPU timing here (JAX 0.7.2, Python 3.12, dynamic parameters, 8 variables):
F/Q trace 0.24 s, compile 0.29 s, warm 0.28 ms; Jacobian trace 0.63 s,
compile 1.03 s, warm 0.77 ms. Warm timings include dispatch and synchronization.

Upstream source/license notices are in `tests/data/va_models/r3_cmc/`.
Its `generate.py` requires bosdi and OpenVAF only for regeneration and records
local normalizations for integer-to-boolean casts, the `gmin` callback,
compact setup cache indices and boolean arithmetic. The generated source
preserves the upstream Educational Community License 2.0 attribution.

A complete intrinsic self-heating netlist explicitly registers the thermal node:

```python
from circulax import compile_circuit
from circulax.components.electronic import VoltageSource

net = {
    "instances": {
        "R": {"component": "r3", "settings": {
            "rc": 2., "c1": 1, "c2": 2, "gth0": 0.01, "cth0": 1e-6}},
        "V": {"component": "voltage", "settings": {"V": 0.1}},
    },
    "connections": {
        "R,n1": "V,p1", "R,n2": "GND,p1", "R,nc": "GND,p1",
        "R,dt": "R,dt", "V,p2": "GND,p1",
    },
    "ports": {"temperature_rise": "R,dt"},
}
circuit = compile_circuit(net, {"r3": R3_CMC, "voltage": VoltageSource})
y = circuit.dc()
temperature_rise = circuit.port(y, "temperature_rise")
```

The thermal self-link registers a free node governed by the model's own
thermal equations. To attach an external thermal network, replace that
self-link with its thermal-port connection.
