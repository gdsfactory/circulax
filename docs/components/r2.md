# R2_CMC native resistors

`circulax.components.r2` provides `R2CMC` (ports `n1,n2`) and `R2ETCMC`
(ports `n1,n2,dt`). These are handwritten JAX implementations of the deterministic
conductance-form R2_CMC / R2_ET_CMC 1.0.1 equations, not OSDI wrappers.

The source reference is [VA-Models commit 6099b4e12e6f66ff530f59b8d01fb909094be85a](https://github.com/dwarning/VA-Models/tree/6099b4e12e6f66ff530f59b8d01fb909094be85a/code/r2_cmc/vacode).
Unmodified reference sources, ECL-2.0 license and notices are stored under
`tests/data/va_models/r2_cmc/`. No generated binary is required at runtime.

```python
from circulax.components.r2 import R2CMC, R2ETCMC

resistor = R2CMC(l=4e-6, w=2e-6, rsh=100, tc1=1e-3, p2=.2, q2=.3)
thermal_resistor = R2ETCMC(r=200, tc1=1e-3, gth0=.002, cth0=.01)
f, q = thermal_resistor(n1=2, n2=0, dt=10)
```

`dt` represents temperature rise in K. Its flow is W and its stored quantity is
J; hence its equation is `Gth*dt - V*I + Cth*d(dt)/dt = 0`. Leaving this circuit
node free solves for self-heating. Connecting it to ground clamps the rise to
zero. Electrical current, thermal flow and stored thermal energy are all scaled
by `m`, the number of parallel segments. With `sw_et=0`, the upstream thermal
stamp degenerates; clamp `dt` to zero when disabling thermal feedback.

Supported deterministic parameters:

| Group | Parameters and units |
|---|---|
| Geometry | `w,l` (m), `r,rsh` (ohms / ohms per square), `c1,c2` (0/1), `scale`, `shrink` (%) |
| Geometry corrections | `xw,xl,dxle` (µm), `sw_efgeo` (0/1) |
| Field dependence | `p2,p3`, `q2,q3` (µm/V) |
| Temperature | `temperature` (ambient K, default 300.15), `trise` (K), `tnom,tminclip,tmaxclip` (°C) |
| Temperature coefficients | `tc1,tc2` (1/K, 1/K²), `tc1l,tc2l,tc1w,tc2w` (with additional µm factor) |
| Multiplicity | `m` (positive, default 1) |
| Electrothermal only | `sw_et`; `gth0,gthp,gtha` (W/K, W/K/µm, W/K/µm²); `cth0,cthp,ctha` (J/K, J/K/µm, J/K/µm²) |

Unspecified `w,l,r` use NaN sentinels to retain the VA `$param_given` behavior:
`l,w` override `r`; `l,r` infer `w`; `r` with optional `w` infers `l`.
Defaults are 1 µm for unspecified dimensions and 100 Ω per square. Sentinel
values are replaced before physics arithmetic. Explicit finite physical
parameters remain differentiable through JAX, including `r`, geometry, field
coefficients and thermal parameters. Discrete topology/contact/geometry-selection
switches and the presence/absence of a parameter are not differentiable choices.

The supported parameter domain has **positive resistance and positive drawn and
effective geometry**, positive field length, `0 <= p2,p3` and `p2+p3 < 1`.
The implementation preserves upstream smooth temperature and TC clipping.
It does not implement degenerate zero-length/zero-resistance/open-width geometry,
resistance-form branch switching, simulator warning/operating-point metadata,
parameter aliases (`dra`, `dtemp`), or noise (`white_noise`, `flicker_noise`).
Diagnostic-only source parameters and simulator-global overrides are not exposed;
use explicit `scale`, `shrink` and `temperature` instead.

## Thermal subcircuit composition

`r2_thermal_subcircuit` returns a body for a recursive netlist. It separates the
nonlinear electrothermal core from ordinary `Resistor` and `Capacitor` branches.
For example:

```python
from circulax import compile_circuit
from circulax.components.electronic import Resistor, Capacitor, VoltageSource
from circulax.components.r2 import R2ETCMC, r2_thermal_subcircuit

netlist = {
    "top": {
        "instances": {
            "R": {"component": "heated_resistor"},
            "V": {"component": "VoltageSource", "settings": {"V": 2}},
            "GND": {"component": "ground"},
        },
        "connections": {"V,p1": "R,n1", "GND,p1": ("V,p2", "R,n2")},
    },
    "heated_resistor": r2_thermal_subcircuit(
        resistor_settings={"r": 100, "tc1": .004},
        thermal_resistance=500,      # K/W, per segment
        thermal_capacitance=.1,     # J/K, per segment
    ),
}
circuit = compile_circuit(netlist, {
    "R2ETCMC": R2ETCMC, "Resistor": Resistor,
    "Capacitor": Capacitor, "VoltageSource": VoltageSource,
})
solution = circuit.dc()
rise = circuit.port(solution, "R~core,dt")
```

This factory replaces all built-in thermal conductance/capacitance parameters;
it sets the core's thermal branches to zero and enables feedback, then adds
external R/C branches. Multiplicity scales both external branches consistently
with the reference. The returned `dt` port also permits extra thermal-network
connections.

## Verification and performance

Run `.venv/bin/python -m pytest tests/test_r2.py -q`. The 28 cases cover geometry
precedence, contact/field scaling, symmetry, finite JIT/AD through temperature
clipping, parameter gradients, analytical self-heating equilibrium, compiled
thermal-subcircuit composition, and reference OSDI comparisons.

With `openvaf-r`, `osdi_loader` and `osdi_jax` installed, tests compile the vendored
reference and compare **F, Q, dF/dy and dQ/dy** across bias, temperature, geometry,
contacts, nonlinearity, multiplicity and thermal geometry terms. They use relative
tolerances of 2e-12 for F/Q and 2e-11 for Jacobians with absolute tolerance 1e-13.
Reference comparisons skip when optional tools are absent. Matching Q and its
Jacobian verifies the thermal storage law; full transient trajectory parity and
noise parity have not been measured.

Measured on this CPU with JAX 0.7.2/Python 3.12.14, a two-terminal nonlinear R2
with explicit geometry took 14 ms to trace F/Q and 56 ms to compile; warm F/Q
calls averaged 58 µs including dispatch and synchronization. Its voltage Jacobian
took 57 ms to trace, 82 ms to compile and 38 µs per warm call. These are single
component measurements, not circuit-solve or full parameter-gradient timings.
Reproduce with:

```sh
.venv/bin/python -m benchmarks.sample_components circulax.components.r2 R2CMC \
  --bias '[1,0]' \
  --settings '{"l":4e-6,"w":2e-6,"p2":0.2,"q2":0.3,"tc1":0.001}'
```
