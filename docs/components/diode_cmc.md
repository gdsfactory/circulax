# DIODE_CMC

`circulax.components.diode_cmc.DIODE_CMC` is the native JAX implementation
of the VA-Models DIODE_CMC 2.0 equations: junction current and charge, series
resistance, original transit-time storage, and Hiroshima recovery and
high-injection equations.

```python
from circulax.components.diode_cmc import DIODE_CMC

models = {"diode": DIODE_CMC}
settings = {"RSCOM": 1.0, "CORECOVERY": 1.0, "NQS": 5e-9, "DEPNQS": 1e-8}
```

The external ports are `A` and `K`. Four internal voltage states are retained:
`v_AIK` (intrinsic cathode), `v_charge_A`, `v_charge_K` (carrier distributions)
and `v_depl_A` (depletion width). The latter three are scaled internal model
coordinates, not externally applied terminal voltages. In particular,
`v_depl_A` represents a length in metres; initialize it near micrometres,
rather than a typical electrical voltage, when supplying custom initial
states. The ordinary DC solver finds their equilibrium from its standard
initialization in the tested default and recovery-enabled circuits.

The full junction model is the default; `SWJUNEXP=1` enables the reference
express branch. `CORECOVERY=0` retains original `TT` storage. With
`CORECOVERY>0`, `TT` storage is disabled as specified upstream and recovery
charge replaces it; `NQS>0` and `DEPNQS>0` enable their respective delay
states. `TYPE=-1` reverses electrical polarity. `DTA` offsets ambient
`_temperature` in kelvin (default 300.15 K). Geometry uses `AB`, `LS`, `LG`,
`SCALE` and `SHRINK`; `MULT` and `_mfactor` retain reference scaling.
Use canonical names: the VA aliases `AREA`, `PERIM`, `PJ`, and `PT` are not
Python constructor fields. `LEVEL`, `VERSION`, `SUBVERSION`, and `REVISION`
are fixed at 2002, 2, 0 and 0.

This coupled nonlinear component supplies `F` and `Q` for DC, linearized AC,
transient and HB analyses. It requires no runtime OSDI compiler or bosdi.
Noise and operating-point metadata are excluded. Keeping the recovery core
together avoids splitting strongly coupled carrier and depletion equations.

## Conditional topology

The VA source short-circuits `AIK` to `K` when series resistance is disabled,
and shorts unused recovery states to ground. Native JAX retains a fixed
number of unknowns: inactive internal coordinates receive explicit algebraic
voltage constraints. In the zero-resistance case, junction current and charge
are transferred to external `K` while `v_AIK=K` is enforced. This preserves
the reference reduced equations, rather than leaving zero residual rows and
a singular circuit. Active series-resistance and recovery rows match the
reference directly.

## Reference and regeneration

The original source, all includes, and complete copyright/license notices
are retained in `tests/data/va_models/diode_cmc/`. The source comes from
[VA-Models commit 6099b4e12e6f66ff530f59b8d01fb909094be85a](https://github.com/dwarning/VA-Models/tree/6099b4e12e6f66ff530f59b8d01fb909094be85a/code/diode_cmc/vacode).
DIODE_CMC was developed by NXP Semiconductors, Hiroshima University and the
Silicon Integration Initiative (Si2); the generated module preserves their
license and acknowledgment.

`regenerate.py` uses OpenVAF-r's unoptimized MIR and bosdi generator commit
`159907ddf29a0225614cf1b7999214401b0b5a2d`. It disables unconditional node
collapse, restores conditional constraints, compacts init-cache indices,
uses ordinary `@component` with JAX differentiation, and replaces boolean
bitwise inversion with `jnp.logical_not` to preserve eager/traced semantics.
The pinned SSA selectors used by the topology repair are validated by the
reference tests. No `ibcast` instructions occur in this model's MIR.

## Verification and performance

OpenVAF-reloaded `20260616-4-g5ed9e63a` generated the OSDI fixtures.
Stored reference `F`, `Q`, `dF/dV`, and `dQ/dV` arrays were generated by
compiling the pinned source to OSDI, not by the native model. Tests cover
defaults, express operation, series resistance plus transit-time storage,
nonquasistatic recovery and depletion delay, quasistatic recovery, reversed
polarity, and large-area/high-injection/temperature variations. Disabled
coordinates are substituted into both models before comparison; inactive
constraint rows are dropped in both models. An optional test recompiles the source and checks
the stored fixtures. Additional tests cover initialization parameter
derivatives, eager/JIT agreement, instantaneous time-domain current, and
compiled Circulax DC circuits with and without active recovery.

A local CPU benchmark with all parameters traced as arguments measured
`F,Q`: 3.50 s tracing, 8.55 s compilation, 525 microseconds warm; Jacobian:
5.02 s tracing, 14.24 s compilation, 1.22 milliseconds warm. Run
`benchmarks/sample_components.py` with the settings above to reproduce the
measurement. Exact command:

```bash
.venv/bin/python -m benchmarks.sample_components circulax.components.diode_cmc DIODE_CMC \
  --bias '[0.3,0,0.01,1e-10,2e-10,1e-6]' \
  --settings '{"RSCOM":1.0,"CORECOVERY":1.0,"DEPNQS":1e-8}'
```

These are development-machine measurements, not guarantees.

Full switching-circuit transient integration and a broad parameter-domain
validation are not yet claimed. Extreme or unphysical internal states can
overflow the upstream exponential carrier-distribution equations; parity
checks use physical depletion widths.
